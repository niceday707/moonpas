# 문파스(MoonPas) 프로젝트 컨텍스트

## 프로젝트 개요
문태고등학교 학생(500명), 교사, 학부모, 졸업생이 함께 사용하는 
학교 커뮤니티 웹 플랫폼. 고려대 "고파스(koreapas.com)" 스타일의 
포탈형 커뮤니티 사이트.
이름: 문파스(MoonPas)

## 기술 스택
- Frontend: Next.js 14 (App Router, TypeScript)
- Styling: Tailwind CSS 4
- Animation: Framer Motion
- Backend/DB/Auth: Supabase (아직 미연동, 더미 데이터로 동작중)
- Font: Pretendard
- 아이콘: Lucide React
- 다크/라이트 모드: next-themes
- 이미지 압축: browser-image-compression
- 배포 예정: Vercel

## 디자인 시스템 (리뉴얼 후)
- 기존 Glassmorphism + 벤토그리드 → 고파스 스타일 포탈형 레이아웃으로 변경 완료
- 레이아웃: 상단 메가메뉴 + 포탈형 3컬럼 (왼쪽: HOT게시물+공지, 가운데: 자유게시판, 오른쪽: 프로필+실시간검색+바로가기)
- 상단에 풀너비 배너 슬라이더 (5초 자동 슬라이드)
- 다크 배경: #0f0f1a / 라이트 배경: #f5f6fa
- 메인 액센트: #7c3aed (보라) / 서브 액센트: #06b6d4 (시안)
- 카드: 깔끔한 흰색/다크 + 미세한 border (Glassmorphism 제거)
- 모서리: rounded-2xl
- 애니메이션: Framer Motion (메뉴 드롭다운, 배너 전환 등 필요한 곳만)
- 모바일 퍼스트 반응형

### 개발 모드 (현재 상태):
- isDev = true 변수로 로그인 체크 ON/OFF 가능
- 현재는 모든 페이지 로그인 없이 접근 가능
- 로그인 필요 페이지 상단에 노란색 "개발 모드" 알림 배너 표시
- 나중에 isDev = false로 바꾸면 실제 로그인 체크 작동

## 사용자 역할 & 배지
- 학생: 파란 배지 (#3b82f6)
- 교사: 보라 배지 (#7c3aed)
- 학부모: 초록 배지 (#10b981)
- 졸업생: 골드 배지 (#f59e0b) + 졸업연도

## 닉네임 시스템
- 로그인 후 첫 접속 시 닉네임 설정 화면 (/profile/setup)
- 닉네임: 2~10글자, 한글/영문/숫자
- 중복 불가, 욕설 필터
- 닉네임 변경: 30일에 1번
- 게시판 표시: 닉네임 + 역할배지만 (학번/이름 절대 표시 안 됨)
- 익명 글: "익명" + 랜덤번호 (예: 익명23)
- 관리자만 실명/학번 확인 가능
- 개발모드: 기본 닉네임 "김민준", 역할 "학생" 고정

## 댓글/대댓글 시스템
- 모든 게시판에 댓글 가능
- 대댓글 1단계까지 (대대댓글은 없음)
- 대댓글은 왼쪽 보라색 세로줄 + 들여쓰기
- 댓글에 좋아요 버튼, 작성시간 표시
- 본인 댓글만 삭제 가능
- 개발모드: 더미 댓글 데이터, 로컬 state로 동작

## 내 프로필 (/profile)
- 닉네임, 역할배지 표시
- 내가 쓴 글 목록
- 내가 쓴 댓글 목록
- 받은 좋아요 수
- 닉네임 변경 버튼
- 프로필 이미지 (기본: 이니셜 아바타)

## 배너 슬라이더
- 대시보드 상단에 풀너비 그래디언트 배너
- 5초 자동 슬라이드, 좌우 화살표 수동 조작 가능
- 배너 추가 방법: Claude Code에 "배너 추가해줘. 제목: OOO, 설명: OOO, 링크: OOO, 배경색: OOO" 라고 말하면 됨
- 나중에 Supabase 연동 후 관리자 페이지에서 직접 추가/삭제 가능하게 할 예정
